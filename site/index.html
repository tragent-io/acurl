acurl

curl for AI agents.

Send one HTTP request as Chrome and as 21 AI agent and crawler profiles, then compare the responses: status, WAF challenge, robots.txt rule, visible-text similarity and product data. Output as a table, JSON, SARIF or JUnit, with a non-zero exit code when a --fail-on rule matches.

$ brew install tragent-io/tap/acurl curl -fsSL https://acurl.dev/install.sh | sh go install github.com/tragent-io/acurl/cmd/acurl@latest npx @tragent/acurl https://example.com docker run --rm ghcr.io/tragent-io/acurl https://example.com

A single static binary for macOS, Linux and Windows on amd64 and arm64. Apache‑2.0.

Results

allowedSame page as the browser baseline.
blockedError status (401, 403, 404, 5xx) instead of the page.
challengedWAF or CAPTCHA challenge page. DETAILS names the vendor.
rate-limitedHTTP 429, with the Retry-After delay.
cloakedVisible-text similarity to the browser is below --cloak-threshold (default 0.5).
robots-disallowedrobots.txt (RFC 9309) disallows this agent.
errorDNS, TLS, timeout or connection reset.

Exit status

0Nothing matched the --fail-on policy.
1A result matched the policy, for example an assistant was blocked.
2A request failed, or acurl was used incorrectly.

Combine blocked, challenged, rate-limited, cloaked, robots, error and score<N, or pass none. Details.

Commands

acurl <url>Request a URL as every profile, classify each response, score the page.
acurl robots <url>robots.txt verdict per agent, Content Signals, sitemaps and llms.txt.
acurl batch [file]Check URL lists, CSV files, stdin or whole sitemaps.
acurl watch <url>...Re-check on an interval and report verdict changes.
acurl report <file>Render a saved JSON report as HTML, Markdown, SARIF, JUnit or CSV.
acurl serveLocal web UI and JSON API.
acurl mcpMCP server over stdio.
acurl tapShow the HTTP requests Claude Code, Codex, Gemini CLI or Grok send to their provider, like tcpdump.
acurl profiles list | showList and inspect agent profiles.
acurl keygenGenerate an Ed25519 key for Web Bot Auth request signing.
acurl initWrite a commented .acurl.yaml.
acurl completionShell completions for bash, zsh, fish and PowerShell.
